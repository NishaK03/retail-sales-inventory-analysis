# Data Dictionary

## Products

| Field | Description | Data Type |
|---|---|---|
| Product_ID | Unique identifier for each product | Text |
| Product_Name | Name of the product | Text |
| Category | Broad product category | Text |
| Subcategory | More specific product grouping | Text |
| Supplier | Supplier providing the product | Text |
| Unit_Cost | Cost incurred by the company per unit | Numeric |
| Unit_Price | Selling price per unit | Numeric |
| Reorder_Level | Stock level at which replenishment should be considered | Numeric |
| Maximum_Stock_Level | Maximum desired inventory level | Numeric |

## Orders

| Field | Description | Data Type |
|---|---|---|
| Order_ID | Unique identifier for an order | Text |
| Order_Date | Date on which the order was placed | Date |
| Store_ID | Identifier of the store handling the order | Text |
| Product_ID | Identifier of the purchased product | Text |
| Customer_ID | Identifier of the customer | Text |
| Quantity | Number of units purchased | Numeric |
| Unit_Price | Selling price per unit | Numeric |
| Discount | Discount applied to the order | Numeric |
| Sales_Amount | Final sales value generated by the order | Numeric |
| Cost_Amount | Cost associated with products sold | Numeric |
| Profit | Profit generated from the order | Numeric |
| Payment_Method | Payment method used by the customer | Text |

## Stores

| Field | Description | Data Type |
|---|---|---|
| Store_ID | Unique identifier for each store | Text |
| Store_Name | Name of the store | Text |
| City | City where the store operates | Text |
| Region | Geographic region | Text |
| Store_Type | Type of retail store | Text |

## Customers

| Field | Description | Data Type |
|---|---|---|
| Customer_ID | Unique identifier for each customer | Text |
| Customer_Name | Customer name | Text |
| Customer_Segment | Customer classification | Text |
| Gender | Customer gender | Text |
| Age_Group | Customer age category | Text |

## Inventory

| Field | Description | Data Type |
|---|---|---|
| Inventory_ID | Unique identifier for inventory record | Text |
| Store_ID | Store associated with inventory | Text |
| Product_ID | Product associated with inventory | Text |
| Stock_Date | Date of inventory record | Date |
| Opening_Stock | Stock available at beginning of period | Numeric |
| Units_Sold | Units sold during the period | Numeric |
| Current_Stock | Stock remaining after sales | Numeric |
| Reorder_Level | Minimum desired stock before replenishment | Numeric |
| Maximum_Stock_Level | Maximum desired stock level | Numeric |
| Inventory_Status | Stock health classification | Text |
